## Recovery observation fact check

Apple documents that [NSFilePresenter only reports coordinated changes](https://developer.apple.com/documentation/foundation/nsfilepresenter); low-level writes bypass its notifications. Recovery publication and the existing fault fixtures include direct durable/atomic file I/O. A presenter alone therefore cannot establish Q130’s recovery-only requirement. The next test must alter and restore a real recovery checkpoint without saving the model, observe canonical unavailable/repaired status through the stream, and verify unchanged source data. Native descriptor-based filesystem observation is the next implementation candidate, not executed evidence.
