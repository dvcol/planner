Q140 leaves unknown, executable and file URL schemes unsupported. Q145 separately asks how supported Mail/Phone/Maps links should open. This slice changes only unsupported navigation; it does not decide Q145 or disable ordinary website JavaScript.

File and executable navigation follow as actual separate supported-boundary investigations rather than assumed coverage from the custom scheme.
