# Canonical recovery copies after later native input

A command or automatic maintenance action can commit natively, then fail to establish its independent recovery copy. If another native writer subsequently adds duplicate membership or expanded-completion rows, ordinary consolidation waits for that pending recovery. Retry previously tried to serialize the unresolved rows directly and stayed incomplete. Neither side could establish a usable current copy.

Both native Retry methods now derive a complete canonical recovery snapshot through the existing resolver. Temporary expanded-row staging uses an isolated context with autosave disabled and is rolled back before publication. The snapshot validates completeness, identities, provenance and history; a native history-token change rejects the attempt. No native maintenance transaction or user command is executed by this projection.

The archive accepts the validated snapshot without replacing its canonical metadata with the unresolved native lineage. Existing component-based callers still build their usual snapshot and share the unchanged receipt, maintenance-evidence, checkpoint and durable-write logic. Immediate publication after an actual native maintenance commit retains its strict raw-graph path.

Command Retry still requires a real applied receipt and preserves its original result. Maintenance Retry still requires a unique verified native commit and its exact durable preparation. A recovery copy may acknowledge that already committed action; it cannot acknowledge the new projected normalization as an executed maintenance action. A subsequent ordinary read performs any needed native maintenance under its own preparation, commit and recovery receipt. Repeating the original Retry returns its original checkpoint.

No public method, agent administration action, model, schema, portable/envelope format, package, target or test seam changes. These remain manual native recovery actions. This uses the approved public Core, real native-input and recovery-filesystem boundaries.
