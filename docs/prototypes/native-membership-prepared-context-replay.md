# Contextual preparation replay before current target resolution

This Q155 A follow-up fixes retries of prepared completion, reorder and reviewed bulk commands after their original targets disappear or are replaced. Previously, those handlers resolved current relationships or required a new bulk review before finding the saved preparation. A missing target could therefore hide the truthful prepared-but-unverified outcome.

Applied receipts still take precedence. Otherwise these handlers look up the saved preparation and match the command against its original bindings before resolving current targets or requiring mutation admission. A matching retry returns the original unverified proposal; it neither applies the prepared graph nor claims a successful command. An altered completion value or placement rejects with operationPayloadMismatch.

New preparations retain original bindings using the existing version-two wrapper and empty membership-observation evidence. Their version-one command fingerprints and applied receipts remain unchanged. Legacy unversioned preparations reconstruct bindings from their complete validated saved graph. Live actions and this reconstruction share the same eligible retired-membership resolver, including exact pair, lifetime and strict-removal-basis checks. No model, portable format, public command, preparation codec, package, target or test-only production hook changes.
