# Item membership summary

The product brief requires the UI to show when an Item belongs to multiple
Lists. Global Item details previously showed no membership information.
They now include one native Label: "Not in a list", "In 1 list" or "In 2 lists".
The count uses the Item's existing complete typed membership references, without
reading List catalogs or changing completion, filtering or saved content.

The existing native Add-to-List journey first fails at the missing summary.
With fourteen production lines added to SavedItemViews, its unchanged tracer
passes on iPhone. Cancel retains one List; Add updates to two; adding the same
membership again keeps two. Original appearance identities, independent local
completion and the two-List summary survive relaunch. The existing empty-list
destination journey additionally proves "Not in a list" before and after Cancel.

The validation record
retains the deliberate red, two passing phone executions and two passing
dark-iPad executions. Four originals are inspected and retained. Phone's later
zero-List assertions and a capture-call formatting correction have explicit
source epochs; both final iPad functions and Mac compilation use identical
1160-input manifests. All passing native executions have zero skips/failures
and SQLite-unlink warnings. The original iPad appearance is restored.

Mac app, Share and native-test compilation passes with nine actual products
verified through the established local ad-hoc recipe. This is compiler evidence,
not Mac interaction or protected signing qualification. Strict affected Swift
formatting, Markdown lint and whitespace checks pass. Core, providers, schemas,
public interfaces and recovery remain unchanged. No new test boundary is added.

This is a read-only global Item summary, not navigation to each containing List
or another contextual-completion control. Full accessibility, actual Mac UI,
physical/cloud acceptance and the human's final review retain their own gates.
Signing stays deferred; optional export/import work remains outside MVP.
