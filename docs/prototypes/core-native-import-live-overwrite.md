# Older-backup values on a restored live owner

## Approved scope and test boundary

Q147 A approves the [concrete Overwrite contract](../import-live-overwrite-contract-review.md), following Q128 A. Use the existing public decode/review/execute/export/recovery/replay interfaces with disposable real storage. The original decoded backup stays immutable. No public type, backup version, persistence schema, target, test seam or agent administration command is added. Signing remains deferred.

## First tracer

Create Museum with Original notes and export its backup. Delete it through review, explicitly restore that backup, then create Other with a locally Done membership to the restored Museum. Edit Museum to Current museum / Current notes. The original backup represents the old closed Item lifetime and owns no links, schedules or other Item associations.

Review ordinary Overwrite of that original backup. It must identify one replacement under the current restored lifetime, with no source restoration, and leave the planner unchanged. Applying it must produce the exact original represented Item values under the retained current lifetime. Every omitted List, membership, completion/history record, deletion marker and restoration-family record must remain unchanged. The expected whole graph uses the original represented Item record with only its current lifetime substituted into the captured current graph; it does not use the production merge to derive expectations.

Require an identical independent recovery graph, exact receipt replay after reopen, and duplicate-free unchanged reimport. The marked fixture remains through test-host exit; successful runs use the existing post-host fixture verifier. Failed invocations retain their actual results and fixtures without passing credit. Further slices qualify closed owned-reference authorization, additional source kinds, lineage and failure handling before the full contract is considered implemented. Q148's separately approved Skip behavior remains a following slice.
