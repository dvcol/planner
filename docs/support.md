# Support

Support for the personal planning app identified by bundle ID `dvcol.planner`.

## Getting started

Create an item from the Add menu, or choose From Link or Text to review a saved
website or Maps link. Add items to reusable lists, then arrange items and lists
as itinerary stops. Calendar schedules are separate from activity estimates.

## Synchronization

Plans work locally. Optional private iCloud synchronization requires the same
Apple Account on each device and the app's iCloud access enabled. Check the sync
status in Settings if changes have not appeared yet. Keep an installation
containing unsynchronized changes until synchronization returns.

## Maps and links

Location lookup, routes, previews and websites require network access and a
working provider. An unresolved location does not mean your saved item was
deleted. Review unresolved locations or retry later. Walking and driving routes
use Apple Maps; public transport can require opening Apple Maps for the full
route.

## Reporting a problem

Use the [project issue tracker](https://github.com/dvcol/planner/issues).
Include the app version, device model, operating-system version, expected
behavior and the steps that reproduce the problem. Issues are public. Never post
credentials, account identifiers or private plans. Share a redacted screenshot
only if useful.

The [privacy policy](privacy-policy.md) explains local storage, private iCloud,
provider requests and website data.
