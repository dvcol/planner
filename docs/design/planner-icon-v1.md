## Generation prompt

```text
Use case: logo-brand.
Asset type: a single finished app icon for Planner, a native Apple app for lists, places and itineraries. Generate one square 1024 × 1024 master, not a presentation board or device mockup.
Primary request: minimalist, simple, memorable design. Create one bold white continuous route/checkmark symbol: a clean check shape with a small circular waypoint integrated at its upper endpoint. The motif should read immediately as an organized plan progressing toward a destination, with very few geometric elements and confident rounded strokes.
Scene/backdrop: a solid blue full-bleed square background, echoing the app's existing blue navigation accent. White symbol only. Use generous internal spacing and a centered, optically balanced silhouette. Keep the mark legible at 32 pixels.
Style: crisp flat vector-like edges and exceptionally restrained native app identity. No texture, glass, bevels, shadows, gradients or 3D.
Text: none.
Constraints: opaque square canvas, no pre-rounded outer corners, no surrounding margin outside the canvas, no border, no typography, no letters, no calendar grid, no extra pictograms, no watermark. Original artwork, not a replica of an existing app icon.
```

The requested size in the prompt did not control the returned dimensions; the
master above retains the original generated pixels.
